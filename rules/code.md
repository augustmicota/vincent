# Kod

- Trzymaj się konwencji repo docelowego; one wygrywają z tym plikiem.
- Zmieniaj tylko to, czego wymaga zadanie. Bez refaktorów przy okazji.
- Nowe zachowanie → test. Bugfix → test, który najpierw failuje.
- Przed oddaniem: testy i lint z pliku projektu przechodzą.
- Bez martwego kodu, zakomentowanych bloków i TODO bez kontekstu.
